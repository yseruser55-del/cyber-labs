## 🔒 SCOPE

## 📖 THEORY
- **rwx:** read(4) write(2) execute(1); эзэн/бүлэг/бусад (owner/group/other)
- `chmod 640 file` → эзэн rw, бүлэг r, бусад юу ч үгүй
- **sudo:** эрх өсгөлт (privilege escalation) хянах
- **Least privilege:** зөвхөн шаардлагатай эрхийг олгох

## ⚙️ PROCEDURE
1. Шинэ хэрэглэгч, бүлэг үүсгэх:
   ```
   sudo adduser analyst
   sudo groupadd soc
   sudo usermod -aG soc analyst
   ```
2. Файл үүсгэж эрх өөрчлөх:
   ```
   echo "secret report" | sudo tee /opt/report.txt
   sudo chown root:soc /opt/report.txt
   sudo chmod 640 /opt/report.txt
   ls -l /opt/report.txt
   ```
   📸 **Screenshot:** `ls -l` гаралт эрхтэйгээ → `LAB-004_DATE_permissions.png`
3. Эрхийг тест хийх: `analyst` болон огт бүлэггүй хэрэглэгчээр унших оролдлого (`su - analyst` → `cat /opt/report.txt`).
4. Суурь hardening:
   ```
   sudo apt update && sudo apt upgrade -y        # патч
   sudo ufw enable && sudo ufw status            # firewall
   sudo systemctl list-units --type=service      # илүүдэл үйлчилгээ харах
   ```
   📸 **Screenshot:** `ufw status` → `LAB-004_DATE_ufw.png`
5. sudo түүх шалгах: `sudo cat /var/log/auth.log | grep sudo`
   📸 **Screenshot:** sudo log → `LAB-004_DATE_sudo-log.png`

## ✅ EXPECTED RESULT
- `analyst` (soc бүлэгт) файлыг уншина, бүлэггүй хэрэглэгч "Permission denied" авна
- ufw идэвхжсэн
- auth.log дотор sudo үйлдлүүд бичигдсэн
