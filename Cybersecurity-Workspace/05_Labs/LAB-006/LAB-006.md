## 🎯 OBJECTIVE
**Өөрөө үүсгэсэн** hash дээр John the Ripper ашиглаж, сул нууц үг хэр амархан эвдэрдгийг, хүчтэй нууц үг яагаад тэсвэртэйг бодитоор харах. Нууц үгийн бодлогыг (policy) ойлгоход суурь болно.

## 🖥️ ENVIRONMENT
- Kali Linux VM (John, hashcat, rockyou.txt суулгаастай) эсвэл Ubuntu VM + `sudo apt install john`
- Snapshot авсан байх

## 🔒 SCOPE
⚠️ **ЗӨВХӨН өөрөө үүсгэсэн hash дээр.** Бусдын, байгууллагын, жинхэнэ системийн hash-д хандахгүй. Энэ бол crack хэрхэн ажилладгийг сурах дидактик дасгал — жинхэнэ нэвтрэлт биш.

## 📖 THEORY
- **Dictionary attack:** толь бичгийн үгсийг hash-лаж тулгах
- **rockyou.txt:** сул нууц үгсийн алдартай жагсаалт
- **Salt:** ижил нууц үгсийг өөр hash болгож, урьдчилан тооцсон халдлагыг хаана
- Зорилго: сул (`password123`) vs хүчтэй (санамсаргүй урт) ялгааг харах

## ⚙️ PROCEDURE
1. Өөрийн тест hash үүсгэх (Linux VM дээр):
   ```
   echo -n "password123" | md5sum | awk '{print $1}' > hashes.txt
   echo -n "Xk9$mQ2!vR7pLw3z" | md5sum | awk '{print $1}' >> hashes.txt
   cat hashes.txt
   ```
   📸 **Screenshot:** `hashes.txt` агуулга → `LAB-006_DATE_hashes.png`
2. John-оор тайлах оролдлого (raw-MD5):
   ```
   john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
   john --format=raw-md5 --show hashes.txt
   ```
   📸 **Screenshot:** cracked болсон сул нууц үг → `LAB-006_DATE_cracked.png`
3. Үр дүнг ажиглах: `password123` секундэд тайлагдана; хүчтэй нь **тайлагдахгүй** (жагсаалтад байхгүй).
4. (Сонголттой) Salt-тай bcrypt hash үүсгэж, илүү удаан болохыг харьцуулах.

## ✅ EXPECTED RESULT
- `password123` → тайлагдана (жагсаалтад бий)
- Санамсаргүй хүчтэй нууц үг → тайлагдахгүй (dictionary-д алга)
- Дүгнэлт: урт + санамсаргүй + salt = тэсвэртэй
