# LAB-002 — WALKTHROUGH (юун дээр, яаж, хэрхэн хийсэн)

## Юун дээр
- Өөрийн Windows компьютер, target = `127.0.0.1` (өөрөө өөрийгөө скан)
- Nmap (нээлттэй эх, стандарт recon хэрэгсэл)

## Яагаад
Халдагч эхлээд recon хийдэг — ямар порт нээлттэй, ямар үйлчилгээ байгааг мэдэх нь довтолгооны гарааны цэг. Хамгаалагч (Blue Team) ч ижил хэрэгслээр **өөрийн** системийн илүүдэл нээлттэй портыг олж хаадаг (attack surface багасгах).

## Хэрхэн хийсэн

### 1. Суулгах
Nmap суулгац (Windows) → Npcap-тай хамт суулгана.
📸 `LAB-002_DATE_nmap-version.png` — `nmap --version` гаралт

### 2. Нээлттэй порт үүсгэх
Flask dashboard асаана (5000 порт нээгдэнэ):
```
cd C:\Users\yalguunjargal.j\cyber-labs\04-dashboard
python app.py
```

### 3. Үндсэн скан
```
nmap 127.0.0.1
```
→ open портуудыг жагсаана.

### 4. Үйлчилгээ таних
```
nmap -sV 127.0.0.1
```
→ 5000 портод "Werkzeug" (Flask-ийн dev server) гэж харагдана.
📸 `LAB-002_DATE_sv-scan.png`

### 5. Гаралтыг нотолгоо болгон хадгалах
```
nmap -sV 127.0.0.1 > scan.txt
```
`scan.txt`-ийг `06_Evidence/Nmap/` руу хуулах.

### 6. Хаалтыг баталгаажуулах
Dashboard-оо `Ctrl+C`-ээр унтраагаад дахин:
```
nmap -p 5000 127.0.0.1
```
→ одоо 5000 **closed/filtered** → "үйлчилгээ унтарвал порт хаагдана" гэдгийг нотолно.

## Гарч болох асуудал
| Асуудал | Шийдэл |
|---|---|
| `nmap` танигдахгүй | PATH-д алга → суулгацыг дахин, эсвэл бүтэн замаар дуудах |
| Бүх порт filtered | Windows Firewall → localhost скан ихэвчлэн асуудалгүй, VM бол firewall шалгах |
| Скан удаан | `-p 5000` гэж тодорхой портоор хурдасгах |

## Юу сурсан
- Recon гэж юу вэ, port scan хэрхэн ажилладаг
- `-sV` нь үйлчилгээний хувилбар хүртэл таамагладаг
- Нээлттэй порт бүр бол боломжит довтолгооны гарц → илүүдлийг хаах нь хамгаалалт
- Зөвшөөрөлгүй скан = хууль зөрчил; зөвхөн өөрийн/зөвшөөрөгдсөн target
