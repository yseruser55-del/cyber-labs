## 🎯 OBJECTIVE
Wireshark-аар сүлжээний урсгалыг (network traffic) барьж авч (capture), TCP-ийн **3-way handshake (SYN → SYN-ACK → ACK)**-ийг нүдээр олж харах. Ингэснээр OSI/TCP-IP онолыг бодит пакет дээр баталгаажуулна.

## 🖥️ ENVIRONMENT
- **Хост:** Таны өөрийн Windows компьютер (VM шаардлагагүй)
- **Tools:** Wireshark (https://www.wireshark.org/download.html)
- **Network:** Зөвхөн **loopback (127.0.0.1)** — өөрийн компьютер дотроо. Гадны сүлжээ рүү хандахгүй.

## 🔒 SCOPE
Зөвхөн өөрийн компьютерийн loopback урсгалыг барина. **Бусдын сүлжээ, байгууллагын траффик барихгүй** — энэ нь зөвшөөрөлгүй бол хууль зөрчинө. Loopback бол 100% аюулгүй, өөрийн чинь л өгөгдөл.

## 📖 THEORY (лабаас өмнө)
- **OSI 7 давхарга** ба **TCP/IP 4 давхарга** ялгаа
- **TCP vs UDP:** TCP найдвартай, холболттой (handshake-тэй); UDP хурдан, холболтгүй
- **3-way handshake:** клиент `SYN` → сервер `SYN-ACK` → клиент `ACK` → холболт үүснэ
- **Port:** 80=HTTP, 443=HTTPS, 22=SSH, 53=DNS

## ⚙️ PROCEDURE
1. Wireshark суулгах. Суулгахдаа **Npcap**-ийг заавал чагтлах (loopback capture-д хэрэгтэй).
2. Wireshark нээж, interface жагсаалтаас **"Adapter for loopback traffic capture"**-г сонгоно.
3. Capture эхлүүлэх (цэнхэр shark сэрвээ товч).
4. Өөр цонхонд loopback урсгал үүсгэнэ. Хамгийн амар арга — өмнө хийсэн **cyber-labs дашбоардаа** ажиллуулах:
   ```
   cd C:\Users\yalguunjargal.j\cyber-labs\04-dashboard
   python app.py
   ```
   Дараа нь browser дээр http://127.0.0.1:5000 нээж, хуудсуудаар дарж орно.
5. Wireshark руу буцаж capture-ээ зогсоох (улаан товч).
6. Filter мөрөнд `tcp.port == 5000` бичээд Enter — зөвхөн дашбоардын урсгал харагдана.
7. `[SYN]`, `[SYN, ACK]`, `[ACK]` гэсэн 3 пакетийг дараалан олох → энэ бол 3-way handshake.

## ✅ EXPECTED RESULT
- `tcp.port == 5000` filter дор олон пакет харагдана
- Эхэнд нь SYN → SYN,ACK → ACK дараалал тод харагдана
- HTTP GET хүсэлт (`GET / HTTP/1.1`) ч харагдаж болно
