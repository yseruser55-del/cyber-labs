## 🎯 OBJECTIVE
Зориудаар эмзэг болгосон **OWASP Juice Shop** веб аппыг өөрийн лабд ажиллуулж, SQL Injection болон XSS-ийг аюулгүй орчинд туршиж, ойлгож, хэрхэн засахыг сурах.

## 🖥️ ENVIRONMENT
- Docker (хамгийн амар) эсвэл Node.js
- Juice Shop нь **зориуд эмзэг** сургалтын апп — өөрийн машин дээр localhost дээр л ажиллана

## 🔒 SCOPE
⚠️ Веб эмзэг байдлыг **ЗӨВХӨН энэ зориуд эмзэг сургалтын апп** дээр, өөрийн localhost дээр турших. Жинхэнэ вэбсайт, байгууллагын систем рүү ХЭЗЭЭ Ч туршихгүй — энэ нь гэмт хэрэг. Build it → Break it → Fix it (зөвхөн өөрийн лаб).

## 📖 THEORY
- **SQL Injection:** оролтод SQL код хийж хайлт/нэвтрэлтийг гажуудуулах
- **XSS (Cross-Site Scripting):** оролтод JavaScript хийж бусдын browser дээр ажиллуулах
- **Input validation** дутуу байх нь үндсэн шалтгаан
- OWASP Top 10 = вэбийн хамгийн түгээмэл 10 эрсдэл

## ⚙️ PROCEDURE
1. Juice Shop ажиллуулах (Docker):
   ```
   docker run --rm -p 3000:3000 bkimminich/juice-shop
   ```
   Browser: http://localhost:3000
   📸 **Screenshot:** Juice Shop нүүр → `LAB-009_DATE_juiceshop-home.png`
2. **SQL Injection (login bypass):** Login хуудсанд Email талбарт `' OR 1=1--` оруулж, нууц үг дурын → админаар нэвтрэхийг оролдох.
   📸 **Screenshot:** амжилттай нэвтэрсэн/алдааны мессеж → `LAB-009_DATE_sqli.png`
3. **XSS:** Хайлтын талбарт `<iframe src="javascript:alert('XSS')">` оруулж, скрипт ажиллаж байгааг харах.
   📸 **Screenshot:** alert гарч ирсэн → `LAB-009_DATE_xss.png`
4. **Fix ойлголт:** энэ эмзэг байдал яагаад болов, parameterized query болон output encoding хэрхэн зогсоохыг тэмдэглэх.
5. (Сонголттой) Juice Shop-ийн Score Board (`#/score-board`)-оор challenge-уудыг хийх.

## ✅ EXPECTED RESULT
- `' OR 1=1--` нэвтрэлтийг тойрч гарна (эсвэл SQL алдаа харагдана)
- XSS payload → JavaScript alert ажиллана
- Яагаад болсон, яаж засахыг ойлгоно
