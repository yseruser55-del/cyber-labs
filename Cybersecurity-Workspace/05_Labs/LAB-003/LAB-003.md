## 🎯 OBJECTIVE
VirtualBox дээр **тусгаарлагдсан (isolated)** виртуал лаб байгуулж, Ubuntu суулгаж, snapshot авч сурах. Дараагийн лабуудын суурь орчин болно.

## 🖥️ ENVIRONMENT
- Хост: Windows (8GB+ RAM зөвтэй)
- **VirtualBox:** https://www.virtualbox.org/
- **Ubuntu Desktop ISO:** https://ubuntu.com/download/desktop (LTS)

## 🔒 SCOPE
Бүх зүйл өөрийн компьютер дотор. Сүлжээг **Host-only эсвэл Internal** болгож, гадны сүлжээнээс тусгаарлана.

## 📖 THEORY
- **Hypervisor:** VM-ийг ажиллуулдаг давхарга (VirtualBox = Type-2)
- **Host OS** (Windows) vs **Guest OS** (Ubuntu)
- **Snapshot:** VM-ийн төлөвийг "хадгалах цэг" — алдаа гарвал буцааж сэргээнэ
- **Isolated network:** Host-only = зөвхөн хост↔VM; Internal = зөвхөн VM↔VM

## ⚙️ PROCEDURE
1. VirtualBox суулгах.
2. **New** → Name: `Ubuntu-Lab`, Type: Linux, Version: Ubuntu 64-bit.
3. RAM: 2048-4096 MB, CPU: 2, Disk: 25GB (dynamic).
4. Settings → Storage → ISO-г оптик дискэнд оноох.
5. Settings → **Network → Adapter 1 → Host-only Adapter** (эсвэл дараа тохируулна).
6. Start → Ubuntu суулгацыг дуусгах (хэрэглэгч үүсгэх).
   📸 **Screenshot:** Ubuntu desktop ажиллаж байгаа → `LAB-003_DATE_ubuntu-running.png`
7. Guest Additions суулгах (дэлгэц томруулах): Devices → Insert Guest Additions CD.
8. **Snapshot авах:** VM цонхны Machine → Take Snapshot → нэр: `clean-install`.
   📸 **Screenshot:** Snapshots жагсаалт → `LAB-003_DATE_snapshot.png`
9. Шалгах: ямар нэг файл үүсгээд, snapshot руу буцааж сэргээгээд файл алга болсныг харах.
