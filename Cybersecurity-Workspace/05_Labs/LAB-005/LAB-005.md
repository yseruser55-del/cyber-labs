## 🎯 OBJECTIVE
Hash функц ашиглан файлын бүрэн бүтэн байдлыг (integrity) шалгаж сурах. Файл өчүүхэн өөрчлөгдөхөд hash бүрэн өөрчлөгддөгийг (avalanche effect) харах. Өөрийн хийсэн cyber-labs хэрэгслийг ашиглана.

## 🖥️ ENVIRONMENT
- Windows (PowerShell) эсвэл Linux VM
- Өөрийн `02-integrity/integrity_checker.py` + dashboard-ийн Crypto Lab

## 🔒 SCOPE
Зөвхөн өөрийн тест файлууд.

## 📖 THEORY
- **Hash:** дурын өгөгдөл → тогтмол урттай "хурууны хээ"; нэг чиглэлт
- **Integrity:** файл өөрчлөгдөөгүй гэдгийг hash харьцуулж батлах
- **Avalanche effect:** 1 бит өөрчлөгдөхөд hash бараг бүхэлдээ өөрчлөгдөнө
- MD5/SHA-1 = эвдэрсэн (collision); SHA-256 = найдвартай

## ⚙️ PROCEDURE
1. Тест файл үүсгэх, SHA-256 авах (PowerShell):
   ```
   "hello world" | Out-File test.txt
   Get-FileHash test.txt -Algorithm SHA256
   ```
   📸 **Screenshot:** анхны hash → `LAB-005_DATE_hash-before.png`
2. Файлыг өчүүхэн өөрчлөөд (нэг үсэг) дахин hash → огт өөр гарна.
   📸 **Screenshot:** өөрчилсний дараах hash → `LAB-005_DATE_hash-after.png`
3. Өөрийн integrity_checker-ээр баталгаажуулах:
   ```
   cd C:\Users\yalguunjargal.j\cyber-labs\02-integrity
   python integrity_checker.py init testdir
   # testdir доторх файлыг өөрчил
   python integrity_checker.py check testdir
   ```
   📸 **Screenshot:** "ӨӨРЧЛӨГДСӨН" илрүүлсэн → `LAB-005_DATE_integrity-detect.png`
4. Dashboard Crypto Lab → Hash Generator дээр ижил текстийн MD5/SHA-256-г харьцуул (MD5 богино, эвдэрсэн гэдгийг тэмдэглэ).
