## 🎯 OBJECTIVE
Ubuntu VM дээр ufw firewall-аар трафик хянах, Suricata IDS суулгаж, сэжигтэй урсгалыг (жишээ: порт скан) илрүүлж alert үүсгэх. Хамгаалалт (firewall) + илрүүлэлт (IDS)-ийг хослуулж сурах.

## 🖥️ ENVIRONMENT
- LAB-003-ын Ubuntu VM (snapshot авсан)
- (Сонголттой) хоёр дахь VM эсвэл хост-оос Nmap скан хийх эх

## 🔒 SCOPE
Зөвхөн өөрийн isolated лабораторийн VM-үүд хооронд. Трафикийг зөвхөн өөрийн VM рүү үүсгэнэ.

## 📖 THEORY
- **Firewall (ufw):** дүрмээр трафик зөвшөөрөх/хориглох (ACL)
- **IDS (Suricata):** урсгалыг дүрэмтэй тулгаж сэжигтэйг **илрүүлж, alert** өгнө (IPS бол хаана)
- **Signature-based detection:** мэдэгдэж буй хэв маягийг таних

## ⚙️ PROCEDURE
### A. Firewall (ufw)
```
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp          # SSH-г зөвшөөрөх
sudo ufw enable
sudo ufw status numbered
```
📸 **Screenshot:** `ufw status` → `LAB-010_DATE_ufw.png`

### B. Suricata IDS
```
sudo apt update && sudo apt install suricata -y
sudo suricata-update                      # дүрэм татах
ip a                                      # interface нэрийг олох (жишээ enp0s3)
sudo suricata -i enp0s3 -D                # сонсож эхлэх
```
### C. Alert үүсгэх (скан илрүүлэх)
Хост эсвэл хоёр дахь VM-ээс энэ VM рүү Nmap скан:
```
nmap -sS <VM-IP>
```
Alert шалгах:
```
sudo tail -f /var/log/suricata/fast.log
```
📸 **Screenshot:** scan-тай холбоотой alert мөр → `LAB-010_DATE_suricata-alert.png`

### D. (Сонголттой) Custom rule
`/etc/suricata/rules/local.rules`-д энгийн дүрэм нэмж, ICMP ping-ийг илрүүлэх:
```
alert icmp any any -> any any (msg:"ICMP ping detected"; sid:1000001; rev:1;)
```
Suricata restart → ping хийж alert шалгах.
